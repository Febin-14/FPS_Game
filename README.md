## Current Features

- Player movement
- Shooting and raycast-based hit detection
- Enemy damage system
- Weapon equip/unequip system
- Inventory system
- Ammo and reload system
- Ammo UI
- Input System integration
- Weapon Manager
- Event-driven UI updates
